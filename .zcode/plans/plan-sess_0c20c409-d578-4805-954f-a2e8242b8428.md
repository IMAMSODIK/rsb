## Plan Implementasi Autentikasi Login

### Ringkasan
Membuat sistem autentikasi lengkap di route `/login` dengan fitur: **Login, Lupa Password, OTP ke Email (untuk reset password), dan Ingat Saya**. Menggunakan **AJAX/Fetch** dan **halaman terpisah** untuk forgot-password & verify-OTP.

### Flow Lengkap

**Login:**
1. User isi email + password → ceklis "Ingat saya" (opsional) → klik Masuk
2. JS kirim POST ke `/login` via fetch
3. Backend: validasi input → cek kredensial → `Auth::attempt()` dengan remember
4. Success → redirect ke `/dashboard`
5. Error → tampilkan pesan error

**Lupa Password:**
1. Klik "Lupa Kata Sandi?" → buka halaman `/forgot-password`
2. Masukkan email → klik "Kirim OTP"
3. Backend: cek email terdaftar → generate OTP 6 digit → simpan ke DB (expires 15 menit) → kirim ke email
4. Redirect ke `/verify-otp?email=xxx`

**Verifikasi OTP:**
1. User masukkan 6 digit OTP dari email
2. Backend: cek OTP valid & belum expired → tandai used
3. Success → redirect ke `/reset-password?email=xxx&token=otp_code`
4. Error → tampilkan pesan, bisa kirim ulang OTP

**Reset Password:**
1. User masukkan password baru + konfirmasi
2. Backend: validasi → update password di DB → hapus session lain
3. Redirect ke `/login` dengan pesan sukses

**Logout:**
1. POST `/logout` → `Auth::logout()` → redirect ke `/login`

### Catatan
- Mail driver saat ini `log` — OTP akan tercatat di `storage/logs/laravel.log` (bukan email asli)
- OTP berlaku **15 menit** dan bisa **dikirim ulang** setelah **60 detik**
- Semua endpoint AJAX mengembalikan response JSON
- Password di-hash otomatis via cast `hashed` di User model
