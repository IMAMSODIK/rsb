## Rencana Implementasi: 9 Modul Master + CRUD + DataTables

### Keputusan (dari jawaban Anda)
- **Foreign key**: konvensi Laravel (`layanan_id`, `kategori_id`, `unit_kerja_id`)
- **Field 'role' di Kategori**: jadi FK ke `unit_kerja` → karena itu dibuat juga master **Unit Kerja** dan **Manajemen User**
- **Form Tambah/Edit**: Modal popup (AJAX)
- **DataTables**: via CDN (Bootstrap 5 styling)
- **Sidebar**: menu master sebagai link datar (flat), BUKAN dropdown/treeview

---

### A. Skema Database (9 tabel + 1 alter)

Urutan migrasi sesuai dependency:

| # | Tabel | Kolom | Dependency |
|---|-------|-------|------------|
| 1 | `unit_kerja` | id, `kode_unit`(unique), `nama_unit`, timestamps | — |
| 2 | **alter `users`** | tambah `unit_kerja_id` (nullable FK) | unit_kerja |
| 3 | `jenis_kinerja_layanan` | id, `kode_layanan`(unique), `uraian`, timestamps | — |
| 4 | `kategori_kinerja_layanan` | id, `layanan_id`(FK), `kode_kategori`(unique), `uraian`, `unit_kerja_id`(FK), timestamps | jenis + unit_kerja |
| 5 | `iku_kinerja_layanan` | id, `kategori_id`(FK), `kode_iku`(unique), `uraian`, timestamps | kategori |
| 6 | `tujuan_rsb` | id, `kode_tujuan`(unique), `uraian`, timestamps | — |
| 7 | `sasaran_program` | id, `kode_sasaran_program`(unique), `uraian`, timestamps | — |
| 8 | `sasaran_strategis` | id, `kode_sasaran_strategis`(unique), `uraian`, timestamps | — |

Semua FK pakai `cascadeOnDelete()` (kecuali users.unit_kerja_id pakai `nullOnDelete()`).

---

### B. Model (9 file baru)

Setiap model: `$fillable`, relasi `belongsTo` (untuk FK), helper method. Contoh `KategoriKinerjaLayanan`:
- `layanan()` → belongsTo JenisKinerjaLayanan
- `unitKerja()` → belongsTo UnitKerja
- `ikuLayanans()` → hasMany IkuKinerjaLayanan

---

### C. Controller (9 file baru, pola resource)

Pola seragam per modul (ikuti gaya AuthController: try-catch, pesan Indonesia, JSON response):

```
index(Request)   → if ajax: return JSON {data: [...]} (eager-load relasi)
                   else: return view('master.xxx.index', [dropdown data])
store(Request)   → validate + create → JSON {success, message}
update(Request,$id) → validate + update → JSON {success, message}
destroy($id)     → delete → JSON {success, message}
```

Tidak ada method `create`/`edit`/`show` (modal only). Pakai `Route::resource(...)->except(['create','edit','show'])`.

---

### D. View (9 file `master/{module}/index.blade.php`)

Setiap view `@extends('layouts.template')` + `@section('content')` berisi:
1. **Breadcrumb** (`.app-hero-header`) — Home / Master / Nama Modul
2. **Card** berisi:
   - Header dengan judul + tombol **"Tambah"** (buka modal)
   - `<table id="datatable">` dengan kolom sesuai modul
3. **Modal Tambah/Edit** (Bootstrap modal, 1 modal untuk both — mode diatur via JS)
4. **JS**: inisialisasi DataTables (AJAX source), handler tombol Tambah/Edit/Hapus, AJAX submit form via fetch, SweetAlert/confirm untuk hapus
